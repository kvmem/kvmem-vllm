# FPS4＋邻块组召回：CWE、QA1、多值退步的逐题分析

后续已完成三道 CWE 的同 Q/K 评分对照，见 [固定操作数诊断](ruler-cwe-fixed-qk-20261023.md)。相同预算、关闭图传播和邻块时，MeanK/FPS4/full-token-max分别保留472/123/147次目标出现，进一步将这三题的主要频次证据损失定位到评分方式；下文保留最初30题观察及其当时的归因边界。

## 结论与比较口径

三个类别的退步不能归为同一种召回错误：CWE 存在明确的频次证据损失，并叠加生成/计数错误；QA1 和多值任务新增的四道失分题，关键答案原句均已完整选回，不能解释为跨页缺失或目标块被邻块挤出。

这里的差值来自同样的原始前10题：旧 MeanK＋max multi 图传播（α=.2），对比新 FPS4＋halo1 预算内分组召回（α=0）。分别为 CWE 97→60、QA1 80→60、多值100→95；不是与历史 sum 组或完整上下文组的差值。新旧输入、种子、采样参数匹配，但评分表示、图传播、picker 及历史运行批次并非单一变量对照。

旧实验：`artifacts/ruler-pooling-queue-20261022-r1/max`。新实验：`artifacts/ruler-fps-native-cpu-halo-256k-20261023-r1`。详细诊断在 `artifacts/ruler-fps-regression-analysis-20261023-r1`。

## 分析方法

- 核对三个类别全部30题的原始答案、官方分数及实际选页；使用原始提交的 token IDs，通过 byte-BPE 精确映射原文位置，不重新分词，不把历史空洞两侧拼接起来计数。
- CWE 主任务清单与 few-shot 示例分开；只有一个词的全部原始 token 均入选时才算一次完整保留。QA1 对照冻结 SQuAD 支持文本；多值核验40个目标值、对应键和整条记录。
- 对本轮捕获的同一份 FPS 种子、图快照、mask、mandatory 集合和预算，离线重放 α=0/.2 与 halo=0/1 的四种选页。α=0 的两种结果与现场记录逐页一致。α=.2＋halo 只是离线假设，当前 live profile 不支持该组合。
- 这是 CPU 上的选页及证据核验，没有重新生成答案、改写官方分数或运行 GPU 测试。离线选页对照不能当成反事实准确率。

## CWE：保住单个词不等于保住词频

这10题各有10个目标词，每词在原主表出现30次；其他词各出现3次。全部目标共3000次原始出现。

| 选页方法 | 目标词完整出现次数 | 频次严格高于所有干扰词的目标数（共100个） |
|---|---:|---:|
| 旧 MeanK＋max 图传播，实际选页 | 1455 | 100 |
| 本轮 FPS，无邻块扩展、无传播，离线 | 383 | 54 |
| 本轮 FPS＋邻块扩展、无传播，实际选页 | 388 | 56 |
| 同一 FPS 分数＋max 图传播，无邻块扩展，离线 | 430 | 64 |
| 同一 FPS 分数＋max 图传播＋邻块扩展，离线 | 403 | 63 |

旧路径平均每个目标保留14.55次，本轮仅3.88次，减少73.3%；不少目标与最多3次的普通词不再有清晰频次差。与此同时，新旧完整保留的全部主表词条数为39182和39713，相差约1.3%，不是总预算大幅减少造成。

由同分数重放可排除两个过强结论：邻块扩展没有造成总体频次损失（383→388略增）；恢复图传播能缓解一部分，但403/430仍远低于旧路径1455，关闭图传播不能解释全部差距。

FPS4 的表示目标是覆盖块内原始 Key，每个 Query/head 对四个代表取最大点积，再作块 softmax。它强调最强局部匹配，不直接保留词频或出现数量。这一设计与“单个键定位”相容，却不保证对分布式计数任务保真。当前证据证明本轮选页破坏了频次优势；尚未在同一份 Q/K 上与 MeanK 对照，因此不能进一步断言全部差异只由 FPS 公式导致，也没有证据声称某个具体代表 Key 必然来自标点或低频词。

CWE 另有生成错误。0004 从100降至0，但新窗口仍完整保留全部10个目标，其中7个出现4–5次，高于干扰词最多3次；模型最终却列出一段普通清单中的词，并有重复。旧路径也保留这段普通清单，不能把其入选本身当作充分原因。全10题中，56个仍有严格频次优势的目标有19个未进入最终编号答案；还存在 `tweeg`→`twegg`、`toddy`→`toddly` 的拼写错误。因而60分不能全部归因于“目标没召回”。

## QA1：两道新增失败的关键原句都在

| 题号 | 旧答案 | 新答案 | 关键证据覆盖 | 解释 |
|---|---|---|---|---|
| 0007 | Christianity (Catholicism) | Christianity | 含 Catholic orthodoxy 的原句31/31 tokens完整 | 新答案只给上位宗教类别，缺少参考要求的教派 |
| 0008 | 含 Norseman, Viking | Norseman | 原文释义句93/93 tokens完整 | 只输出部分释义，未包含官方所有参考均要求的 Viking |

0007 的 Catholic 所在页 FPS 排名第8，0008 的 Viking 所在页排名第44；当前无 halo 选页也完整保留这些关键句。既没有目标低排，也没有邻块扩展挤走答案。

两题都按官方规则保留0分。0008 对答案表达范围敏感；0007 是具体程度不足，不能统一说成“只是同义词”。原有两道失败0005/0006在新旧组都为0，不构成这次20分下降。

选页完整只能排除直接证据缺失，不能证明模型内部读取一定正常。不同周边内容、历史 K/V 表征、批次与采样轨迹仍可能影响最终回答。尚未做固定同一份 K/V 的生成对照，无法把这种回答变化归到单一优化开关。

排名按本次记录的完整 score_mask 评分域计算。两条记录的键、数字及原句都在同一块内；新实际选页、相同 FPS 无 halo 选页、旧 max 选页均完整覆盖。没有跨页问题，且 Query 后没有再次 pressure 重选将其淘汰。

两题分别正常生成387和484 tokens后以 stop 结束，均非生成长度截断；从应答4项变成只答3项，所以每题100→75，十题均分100→95。0003的目标曾不在最后一次 prefill pressure 窗口，但最终 Query 已完整选回；0009在该 pressure 窗口中也已完整，不能用同一个“此前丢失”理由解释两题。

## 工程判断与下一步

没有发现此次下降由 CPU 代表选择算错、缓存错位或预算超额直接导致的证据。既有固定输入组件核验中，CPU 原生路径与参考的全部代表位置及 Key 字节一致；本次执行审计和原生 picker 重放通过。这不等于证明不同 live 运行的 K/V 表征完全一致。

更有针对性的验证顺序：

1. 固定同一份 Q/K、mask、预算及 picker，对比 MeanK、FPS4 和保留平均信号的组合评分，先测 CWE 的频次证据保真。图传播与邻块开关单独控制，不用现有最终分数替代因果实验。
2. 对 QA1、多值固定同一份已选 K/V，核对生成时真正使用的视图、输入打包和回答完整性；如需重跑，保留原始答案并独立标记。增加邻块不是这四道新增失分题的直接解法。
3. 保留官方评分；语义别名或完整性诊断可单列，不能通过修改参考答案来抬高当前结果。
